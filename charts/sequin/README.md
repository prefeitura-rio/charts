# sequin

Helm chart for [Sequin](https://github.com/sequinstream/sequin), with external PostgreSQL (Cloud SQL) and Valkey cache.

> Forked from https://github.com/sequinstream/helm-chart-sequin, adapted for our purposes.

## Install

```bash
helm install my-release oci://ghcr.io/prefeitura-rio/charts/sequin
```

See `values.yaml` for configuration options.
